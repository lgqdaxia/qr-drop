# 解码 · QR

极简二维码图片解码。拖入、选择或粘贴图片，识别后复制内容或打开链接。

图片只在浏览器本地处理，无上传、无统计、无外部资源请求。支持浅色与深色模式、手机与键盘操作。

界面按浏览器语言偏好自动选择简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语或葡萄牙语；没有匹配语言时使用英语。二维码内容保持原文。

左上角国旗可手动切换语言并记住选择；菜单中的地球图标恢复自动选择。切换时保留当前二维码内容。

## 运行

用任意静态 HTTP 服务打开此目录，或直接使用 GitHub Pages。无需安装依赖或构建。

GitHub Pages：选择 `main` 分支的根目录 `/`。

一次读取一张图片中的一个二维码；动态图片读取静态帧。图片最大 30 MB / 6400 万像素。模糊、遮挡或特殊编码的二维码可能需要裁剪或更换图片。
